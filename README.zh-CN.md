# Lumencraft 中文说明

一个在浏览器里运行的 Minecraft 风格方块沙盒游戏，画面参考了流行的"写实光影包"：基于物理的天空、柔和阴影、体积云、丁达尔光束、会反射的水面、泛光和电影感色调映射。

纯 WebGL 2 + JavaScript，没有运行时依赖。地形、纹理和声音都是程序生成的，仓库里没有图片或音频素材。

界面支持中文和英文，在标题画面右上角或 **设置 → 通用** 里切换。

## 怎么玩

```bash
npm install      # 只有打包（npm run build）才需要
npm run dev      # 打开 http://localhost:8080
```

打包成单个文件：

```bash
npm run build    # 生成 dist/index.html，双击就能打开，也可以放到任何静态网站上
```

## 在不同设备上玩

### 电脑

键盘鼠标操作，点击画面锁定鼠标即可。显卡较弱（核显）时选"中"或"低"画质。

### 手机和 iPad

- 画面左侧任意位置按住就是摇杆，推到边缘是疾跑。
- 右侧滑动转视角；轻点放置方块，长按挖掘方块。
- 右下角的按钮：跳跃、潜行、飞行、挖掘、放置；右上角：全屏、方块栏、暂停。
- 底部物品栏可以直接点选。
- 在 **设置 → 操作** 里可以调整按钮大小、不透明度、视角速度和震动。
- 手机建议横屏。想要全屏：
  - iPhone / iPad：用 Safari 打开，点"分享" → "添加到主屏幕"，之后从主屏幕图标打开就是全屏。
  - 安卓：点右上角的全屏按钮，或者在浏览器菜单里选"添加到主屏幕 / 安装应用"。

### 当贝投影仪、电视盒子（配合手柄）

1. 用蓝牙连接手柄（Xbox、PS、Switch Pro 或其他标准手柄都行）。
2. 在投影仪的浏览器里打开游戏地址。
3. 先点 **设备检测**，确认"WebGL 2"和"浮点渲染目标"显示"支持"，并且能检测到手柄。如果不支持，换一个新一点的浏览器（基于 Chromium 内核的都可以）。
4. 投影仪芯片的图形性能大约相当于中低端手机，游戏会自动选择"流畅"画质并开启动态分辨率。卡顿的话把 **视野距离** 调小。
5. 想要最好的画质：用电脑通过 HDMI 接投影仪，手柄连在电脑上。

菜单里也能用遥控器：方向键移动，确认键选择，返回键后退。

## 生存模式和生物

新建世界默认是**生存模式**（创建时可以选创造模式和难度，之后也能在"设置 → 世界"里随时切换）。

- **生命值和氧气**：十颗心。摔落、溺水、熔岩、火、仙人掌和怪物都会让你受伤。生命值会慢慢恢复，吃东西恢复更快（手里拿着食物时右键 / LT / 轻点屏幕）。
- **天黑以后怪物出没**：僵尸（白天会被太阳烧）、苦力怕（嘶嘶响后爆炸）、骷髅（保持距离射箭）、蜘蛛（能爬墙、会扑人）。它们会用 A* 寻路绕过障碍找到你。"和平"难度没有怪物。
- **动物**白天在草地上出现：牛、猪、羊（有几种毛色）和鸡，能掉落食物和材料。
- **挖掘和工具**：按住挖掘，方块上会出现裂纹。石头和矿石必须用镐才会掉落；用对工具（镐、斧、锹）挖得更快。工具和武器会磨损。剑、镐、斧、锹、锄都有木、石、铁、金（挖得最快但很不耐用）、钻石、下界合金六种（钻石装备 + 下界合金锭升级，合金锭来自下界深处的远古残骸）。
- **盔甲**：皮革、锁链、铁、金、钻石、下界合金的头盔、胸甲、护腿、靴子。穿上后（护甲值显示在红心上方，别的玩家也能看到你穿着）能挡住怪物、箭、火和爆炸的伤害，同时会慢慢磨损。
- **战斗**：剑的伤害更高，跳起来攻击是暴击，击中会把怪物击退。弓按住蓄力，需要箭。
- **背包**：36 格背包 + 9 格快捷栏 + 4 个盔甲格。点一下拿起一组物品（右键拿一半），再点或直接拖到任意格子放下（右键放一个）；Shift+点击在背包和快捷栏之间移动，盔甲会直接穿上；鼠标放在格子上按 1–9 可以和快捷栏交换。创造模式还有带分类标签、搜索框和垃圾桶的全部物品栏。
- **合成**：用身上材料能做的配方都会列出来，点一下就能合成（各种材质的工具和盔甲、床、弓箭、打火石、末影之眼、面包、箱子、熔炉、门、栅栏、楼梯、台阶、桶……）。
- **箱子和熔炉**：箱子能放 27 组物品，放进去的东西会一直留在世界里（Shift+点击可以整组移进移出）。熔炉用来烧炼和烤东西：粗铁、粗金（现在铁矿、金矿挖出来就是这个）炼成锭，沙子烧成玻璃，圆石烧成石头，黏土球烧成砖，原木烧成木炭，生肉烤熟。燃料可以用煤炭、木炭、木头或熔岩桶；人走开了也会继续烧，点着的时候会发光。
- **建筑方块**：十种材质的台阶和楼梯（不用跳就能走上去，两块台阶叠成一整块），能开关的门（两扇并排会变成双开门），会自动连在一起、跳不过去的栅栏，栅栏门、活板门、能爬的梯子、玻璃板、铁栏杆，还有可以写字的告示牌（中文英文都行）。
- **水和熔岩会流动**：液体从源头向外流（水流 7 格，熔岩 3 格，下界里熔岩也流 7 格），遇到坑会往下流，源头没了就会退去。两个水源中间的空格会变成新的水源；熔岩碰到水会变成黑曜石或圆石。桶可以舀起液体再倒出来，拿空桶右键点牛能挤牛奶。
- **树会重新长出来**：树叶偶尔会掉树苗，种在草方块或泥土上就会长成橡树、白桦或云杉。骨粉（骨头合成）能让树苗和庄稼长得更快，撒在草地上还会冒出花草。
- **掉落物**（按 `Q` 丢出、从背包里拖出去、死亡掉落、挖方块掉落）会一直躺在地上，走过去才会捡起来；联机时大家都能看到，谁先走到就归谁。
- **种地**：拿锄头把草方块或泥土耕成耕地，种上小麦种子（打草丛有几率掉落），成熟后收割做面包。庄稼按世界时间生长，联机时大家看到的是同一片麦田。
- **太空、月球和火星**：一直往上飞（创造模式飞行，或者鞘翅加烟花：空气越稀薄烟花推得越猛），天空会慢慢变黑。飞到海平面以上 2000 格（按 1 格 = 50 米算就是 100 公里），大气层就到头了，你进入了太空，脚下是一个弧形的地球：大陆、海洋、冰盖、云层，夜晚那一面还有村庄的灯光，全都来自这个世界自己的地形。月球绕着地球转（它的月相就是夜空里看到的月相），火星、木星（条纹和大红斑）、土星（光环）各在各的位置。屏幕上的标记会显示每个星球有多远；离所有星球越远，飞得越快。靠近星球时你会跟着它一起转，停下来就一直悬停在同一片地面上空。飞近月球或火星就能降落，宇航服的推进器几秒钟就把你送到地面。木星和土星没有地面：导航信标会把你引到漂浮在云层上的空间站（木星的在大红斑上空，土星的在光环下面），有玻璃穹顶罩着的樱花小花园、停机坪，脚下是一望无际的彩色云海（掉下去推进器会把你送回来）。月球上是灰色的月壤、暗色的月海和环形山，重力只有地球的六分之一，黑色的天空里挂着地球，也会有圆缺。火星上是红色的沙和岩石、火山、大峡谷和极地冰盖，天空是黄褐色的，日落却是蓝色的。宇航服的推进器会让你平安落地，也能把你重新送上天（空中再按一次跳跃并按住），飞得够高就又回到太空了。那里没有空气，火点不着；下界传送门也只在主世界和下界之间有用。
- **公主抱**：可以把村民、朋友或小动物抱起来带着走（单人游戏里还能带着穿过传送门、带去太空）。村民被抱起来会说话，也会记住这件事；把村民抱到离它家很远的地方放下，它就在那里安家，所以你可以把村民搬到自己盖的房子里。联机时大家都能看到谁抱着谁，被抱的人连按三下跳跃就能挣脱。
- **飞碟**：银色的科幻飞碟，玻璃圆顶，一圈流动的彩灯，三条着陆腿。创造模式物品栏里直接有；生存模式用 4 个铁块、4 块玻璃、2 个灯笼和 2 颗钻石合成，64 格的油箱可以加煤炭或木炭（1 格）、烈焰棒（2 格）、岩浆桶（8 格）：手持燃料右键飞碟，或者在飞行面板里点"加燃料"。放下飞碟，右键就能坐进去。飞行面板列出能去的地方（地球、月球、火星，木星和土星的空间站）、每趟要花的燃料和这趟飞多久：30 秒、1 分钟、3 分钟，或自定义 15 秒到 15 分钟，想多看会儿风景就选长一点。剩下的交给自动驾驶：倒计时、点火、喷烟、轰鸣起飞，冲出大气层，绕过星球穿越太空，最后降落在目的地固定的发射台上（地球上是飞碟第一次放下的地方，月球和火星是世界中央的发射台，空间站是它们的停机坪）。飞行中转动视角，镜头就绕着飞碟转；滚轮或行程条上的 + − 拉近拉远。点"自己驾驶"就能手动飞：移动键控制方向（朝镜头看的方向飞），跳跃上升，下蹲下降，疾跑加速（飞得越高、在太空里越快）。在平地上方一直往下降，它会自己减速着陆；不平的地方不让降落；撞到地面或墙壁只会弹开，毫发无损。往上飞出大气层就到了太空，可以降落到任何星球，也可以随时打开面板重新交给自动驾驶。落地后按下蹲走出飞碟，飞碟留在原地。抱着村民上飞碟，它在起飞、太空和到达时都会说出自己的感受。生存模式下自己驾驶每半分钟消耗 1 格燃料。
- **床**：16 种颜色。晚上睡觉可以直接到天亮（联机时要主世界的所有人都上床），死后会在床边重生。在下界和末地用床会爆炸。
- **下界**：用黑曜石搭一个 4×5 的框，用打火石点燃就能打开下界传送门。下界有岩浆海、下界岩洞穴、荧石、石英、灵魂沙、远古残骸和下界要塞；有僵尸猪灵（打它才会还手）、会吐火球的恶魂、掉烈焰棒的烈焰人。下界走 1 格等于主世界 8 格。
- **末地**：末影之眼（末影珍珠 + 烈焰粉）扔出去会飞向最近的要塞。把要塞传送门房间的 12 个框架都放上末影之眼，跳进去就到了末地。末地岛上十根黑曜石柱顶上的末地水晶会给末影龙回血，先把水晶打掉，再打败末影龙（屏幕上方有血条），回家的传送门就会打开，还有龙蛋。末影人会掉末影珍珠，扔出去可以瞬间传送。
- **死亡**后身上的东西都会掉在原地，你会在床边（床还在的话）或出生点重生。
- **多个存档**：标题画面的"选择世界"里可以有任意多个单人世界，每个世界有自己的名字、模式、建筑、背包和时间，可以随时进入、重命名或删除。
- **饥饿值**：红心旁边有十个鸡腿。奔跑、跳跃、游泳、战斗和回血都会消耗饱食度；吃东西要按住使用键一会儿，每种食物补充的饥饿值和饱和度不同。吃饱时回血快，饿到零会掉血。腐肉、生鸡肉、河豚吃了可能会不舒服。
- **经验和附魔**：打怪、挖矿、烧炼、交易、繁殖、钓鱼都会掉绿色的经验球，等级显示在物品栏上方。附魔台（书、钻石、黑曜石）周围最多摆 15 个书架，每次给出三个附魔选项，消耗等级和青金石：锋利、亡灵杀手、抢夺、效率、时运、精准采集、耐久、保护、摔落保护、力量、火矢、无限、快速装填、多重射击、穿透、饵钓、海之眷顾等。经验修补（有些村民卖的东西上带着）能用捡到的经验修理手里和身上的装备。
- **药水**：酿造台用烈焰粉作燃料，把水瓶酿成药水。先放下界疣做出粗制的药水，再放闪烁的西瓜片、恶魂之泪、烈焰粉、糖、岩浆膏、金胡萝卜、河豚、蜘蛛眼、幻翼膜或粘液球，就得到治疗、再生、力量、迅捷、抗火、夜视、水下呼吸、剧毒、缓降或跳跃药水；发酵蛛眼把它们变成伤害、虚弱、缓慢或隐身药水，加火药就做成喷溅药水。身上的效果显示在右上角，喝牛奶能全部清除。
- **盾牌、弩、钓鱼竿、不死图腾**：副手拿盾牌可以挡住正面的攻击（被斧头砍会暂时放下）。弩按住装填，再按一次发射（多重射击一次三支箭，副手有烟花就发射烟花）。钓鱼竿能钓鱼，偶尔钓到宝藏或杂物，也能勾住动物把它拉过来。任意一只手拿着不死图腾，可以免死一次。
- **村庄**：土径连着房子、农田、水井、铁匠铺和路灯，有平原、沙漠、热带草原、针叶林和雪原几种风格。村民有职业（农民、渔夫、牧羊人、制箭师、图书管理员、制图师、牧师、盔甲匠、武器匠、工具匠、屠夫、皮匠、石匠），用绿宝石交易，每天早上补货，晚上回家。**铁傀儡**守护村庄（用 T 形的铁块加一个南瓜也能造出来）。
- **会说话的村民**：对村民右键（手机上点一下）就能聊天。每个村民都是一个“人”：有自己的名字、性格、小怪癖和声音，所有玩家看到的都一样。他们记得每个玩家（说过的话、送过的礼、帮过的忙、打过他一下），会传村里的八卦（谁去了下界、谁掉进了岩浆、谁打败了末影龙），会派带奖励的任务（任务卡上显示你身上有几个，在聊天界面里点“交付”），会给好朋友送小礼物，能被你说动给交易打折，或者跟着你走。村民说的话显示在头顶，并用设备自带的声音念出来（离得越远越小声，设置里可以关掉）；你可以打字、点现成的话，也可以直接说话（浏览器支持的话）。**设置 → 声音 → 试听** 会马上说一句话，并告诉你这台设备能不能朗读、不能的话该怎么办（在微信、QQ 等 App 里打开的网页通常不能朗读）；iPhone 和 iPad 开着静音开关也能听到游戏声音和村民说话。回答来自服务器上的大模型（默认是你的 ATRIA 大模型，也可以换成任何 OpenAI 兼容接口），Key 只放在服务器上；没设 Key、或者大模型忙/太慢时，由脚本对话顶上。联机时附近的人都能听到村民说话，记忆和世界一起保存在服务器上；单人游戏的记忆存在存档里。大模型说要给的东西都会检查（不会送出一堆钻石），请求次数也有限制。蹲下再右键可以直接交易。
- **村庄生活**：村民知道附近真实存在的地方（沙漠神殿、女巫小屋、掠夺者前哨站、海底神殿、林地府邸、废弃矿井、另一个村子、要塞，都是按世界本身的生成规则找出来的）。问他们“附近有什么好玩的地方？”，他们会告诉你在哪个方向、大约多远，还会提醒那里有什么危险，同时屏幕上会标出那个地方（在身后时屏幕边上有箭头指路），一直到你走到那里为止；暂停菜单里可以取消标记。找到以后，告诉你的那个村民会很高兴，村里也会传开。村民之间时不时会停下来面对面聊几句，聊天内容由服务器上的大模型来写（联机时附近的人看到、听到的是同一段对话；没有大模型时用脚本对话）。他们的心情会表现出来：头顶会冒出爱心、音符、生气的青筋、感叹号或问号，还会点头、摇头、挥手、欢呼、蹦跳、跺脚。好朋友路过时他们会挥手打招呼；你在他们旁边打跑怪物，他们会欢呼，也会更喜欢你；你拆他们的房子他们会生气（拆你自己放的方块不算）；打雷时他们会跑回家；你从天上落下来，他们会围过来看。
- **宠物和家畜**：用骨头驯服的狼会跟着你、帮你打怪，可以让它坐下；用生鱼驯服的猫能吓跑苦力怕。给两只动物喂它们爱吃的（小麦、胡萝卜、种子）就会生出小宝宝，小宝宝会慢慢长大。用剪刀剪羊毛（会重新长出来），用桶挤牛奶。水里有鳕鱼、鲑鱼、热带鱼、河豚和鱿鱼。
- **新的怪物**：女巫（扔药水，自己喝药水）、史莱姆（死后分裂，出现在沼泽和史莱姆区块）、幻翼（三天没睡觉的人会被它俯冲攻击）、掠夺者巡逻队和前哨站、林地府邸里的卫道士和唤魔者（从地下召唤尖牙）、海底神殿里的守卫者和远古守卫者、末地城里的潜影贝、废弃矿井里刷怪笼刷出的洞穴蜘蛛、凋灵骷髅，还有**凋灵**（在 T 形灵魂沙上放三个凋灵骷髅头颅召唤）。
- **交通**：船在水上划；矿车在铁轨上跑，铁轨铺的时候会自动转弯、上坡（动力铁轨给矿车加速）；马要先骑到它不再把你甩下来才算驯服，再装上鞍；还有**鞘翅**（穿在胸甲栏，拿在手里按使用键也能穿上）：跳起来后在空中再按一次跳跃就开始滑翔（跳起来马上按也行，和 Java 版 1.15 以后一样；创造模式下这第二下是展开鞘翅，不会切换成飞行），速度越快视野越宽，耳边是呼呼的风声。飞行中使用烟花火箭会朝视线方向猛地加速（和原版一样，最快约每秒 34 格），两边翅膀会拖出变换颜色的闪烁火花，中间是火箭喷出的火焰。穿着鞘翅但还没展开时（跳起、下落、飞行中，或者站在地上抬头看天空而不是对着方块）使用烟花，会直接展开鞘翅带你飞起来。
- **压力板**：有玩家、生物或物品站在上面时，会打开旁边的门、栅栏门和活板门，离开后再关上（石质压力板只感应玩家和生物）；铁门只能这样打开。用打火石（或压力板）点燃的 TNT 过一会儿就会爆炸。
- **结构**（新世界里）：村庄、沙漠神殿（小心 TNT 陷阱）、废弃矿井（铁轨、蜘蛛网、洞穴蜘蛛刷怪笼）、地牢（刷怪笼和宝箱）、女巫小屋、掠夺者前哨站、海底神殿、林地府邸，以及末地城和末地船（船上有鞘翅，打败末影龙后从末地外围的折跃门过去）。结构里的箱子第一次打开时才决定里面有什么。

## 多人联机和语音聊天

把游戏部署到你自己的云服务器上，朋友们用浏览器打开网址就能进入同一个世界。部署步骤见 [server/README.zh-CN.md](server/README.zh-CN.md)。
最简单的启动方式是 `node server/server.mjs`，不需要安装任何第三方包。

- **加入**：标题画面点"多人游戏"，填上名字（服务器设置了密码就再填密码），点"加入"。如果网页就是从这台服务器打开的，地址留空即可。
- **共享的世界**：大家在主世界、下界、末地、月球和火星放置和破坏的方块、末影龙的战况、箱子、熔炉、告示牌和时间都会同步。每个人的背包、盔甲、血量、所在维度和位置由服务器按名字保存，下次用同一个名字进来会恢复。大家能看到别人手里拿的东西和身上穿的盔甲。
- **共享的东西**：掉在地上的物品所有人都能看到，谁先走过去就归谁。箱子和熔炉同一时间只能一个人打开（别人会看到"某某正在使用"）；没人打开时熔炉在服务器上继续烧；箱子被砸掉，里面的东西会掉出来，大家都能捡。
- **太空**：在太空里的玩家能互相看见，位置是相对离自己最近的星球算的，所以大家看到的脚下地面是同一片。在太空中下线，下次进来还在原来那片地面上空，不管月球这段时间转到了哪里。
- **飞碟**：大家都能看到飞碟起飞、飞行和降落，还有它的火焰和烟雾。右键别人已经落地的飞碟就能请求登船：最多三名乘客坐在甲板上，飞碟去哪儿就跟到哪儿（包括太空和其他星球），镜头可以随意绕着飞碟转；落地后按下蹲下船。停着的飞碟谁都可以坐进去：原来运行它的玩家的游戏会把它交过来。
- **睡觉**：主世界里所有人都躺到床上，夜晚就会跳过；在下界或末地的人不算在内。
- **一起打怪**：每个人的电脑负责计算自己附近的怪物和动物，并同步给附近的人。你可以打别人那边的僵尸，被你打死的怪物掉落物归你。
- **村民和宠物**：结构里的村民、铁傀儡和猫整个服务器只生成一次（谁先到谁那边生成）。会一直留着的生物（村民、宠物、马、船、繁殖出来的动物）由服务器保存；负责计算它们的人下线或走远后，会交给附近的其他玩家继续计算，不会消失。
- **天气**：联机时天气由服务器统一决定，所有人同时下雨、同时放晴。设置里天气选"多变"就跟随服务器；选"晴天""下雨""雷暴"则只改变你自己看到的天气。
- 酿造台和熔炉一样在服务器上继续酿造；结构里的宝箱由服务器生成一次；附魔会随掉落物一起同步；每个人的饥饿值、经验和药水效果也由服务器保存。
- **聊天**：按回车（或触屏的聊天按钮）输入文字。
- **语音**：暂停菜单里点"开启麦克风"，或按 V / 手柄方向键上 / 触屏麦克风按钮。
  - "附近语音"：离得越远声音越小，还能听出对方在左边还是右边。
  - "全员语音"：所有人音量一样。
  - 麦克风只能在 https 网址下使用。没有麦克风的设备（比如投影仪）也能听别人说话。
- **注意**：claude.ai 上的预览链接不能联机和语音，需要从你自己的服务器打开游戏。

## 世界

- 主世界就是一个真实大小地球的地图（1 格 = 50 米，半径 6360 公里）。离世界中心 4 万格以内还是原来的地形。再往外，大陆、海洋和气候随纬度变化：南北两极是冰雪，干旱带里是沙漠，赤道附近（世界中心往南大约 5.3 万格）是丛林。月球和火星是另外两个独立的世界。
- 无限的地形，每个区块 16×16×384 格（和原版一样高：海平面 63，山峰能到 200 多格）。只有区块里有东西的那一段才计算光照和网格，所以不会因为变高而变卡。
- 十六种群系：平原、森林、白桦林、针叶林、雪原针叶林、沙漠、沙滩、海洋、河流、山地，以及丛林（巨型丛林树、藤蔓、西瓜）、热带草原（金合欢）、沼泽（浑水、睡莲、垂着藤蔓的橡树）、恶地（一层层陶瓦的平顶山）、樱花林（粉色花瓣）和黑森林（茂密的深色橡树）。
- 新增的树（丛林、金合欢、深色橡木、樱花）都能用树苗种出来；巨型丛林树和深色橡树要把四棵树苗种成 2×2。
- 在 384 格世界之前创建的存档会保留原来 128 格高的地形（每个世界都记住了自己用的地形生成器版本），新建的世界才用新地形。

## 画质

树叶的"蓬松叶片"和 3D 草丛现在默认关闭（更流畅，看起来也更干净），需要的话可以在"设置 → 画面"里单独打开。

**设置 → 画面** 里有五档预设：流畅、低、中、高、极致。第一次启动会根据设备自动选择；刚开始玩的几分钟里如果帧率明显低于 30，会自动降一档。

- **动态分辨率**：帧率低于"目标帧率"时自动降低渲染分辨率，有余量时再升回来。
- **体积云**：云单独做了多帧累积（不依赖 TAA），所以在"流畅"和"低"画质下也是干净的，不会再出现噪点网格。云层会随着地球弯曲。
- **从高空到太空**：越飞越高，下面的风景会变成整个星球。大气用透射率表和天空视图表（Bruneton、Hillaire 的做法）计算，在任何高度看都对：黑色天空下一圈蓝色的大气边缘，晨昏线上的日出日落。地面来自这个世界自己的地形生成器画出的地图（近处、中距离和整个星球三张，在 Web Worker 里生成，按像素大小取样），还有云层、海面的反光、夜晚被月光照亮的云和村庄的灯光。月球用 Lommel-Seeliger 反射模型，还有地球反照的"地照"；火星有一层稀薄的尘埃大气；木星和土星有条纹云带，土星的光环上有行星的影子；星星和银河固定在天上。天空变黑以后，曝光按太阳光来算，地球不会发白。

## 存档

每个世界（种子、位置、时间、物品栏、箱子里的东西和你改过的每个方块）都保存在浏览器的 IndexedDB 里。在标题画面点 **新建世界** 可以再建一个新世界（原来的世界会保留），可以起名字、输入种子；点 **选择世界** 可以在各个世界之间切换、重命名或删除。

## 部署到 GitHub Pages

`.github/workflows/pages.yml` 会在每次推送到 `main` 时构建并发布 `dist/`。第一次使用前，在仓库的 **Settings → Pages → Build and deployment → Source** 里选 **GitHub Actions**。

Lumencraft 是受 Minecraft 启发的个人作品，与 Mojang、微软没有关系，也没有使用它们的素材。
